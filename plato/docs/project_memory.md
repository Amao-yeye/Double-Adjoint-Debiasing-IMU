# PLATO Project Memory

Last updated: 2026-05-20

## Objective

PLATO aims to learn IMU bias dynamics from privileged accurate trajectory observations. ORB-SLAM3 stereo VO will provide high-quality pose trajectories on visually favorable data. Those trajectories will supervise Neural ODE models for gyroscope bias `b_g` and accelerometer bias `b_a`. Learned bias trajectories or dynamics will be exported for evaluation in OpenVINS under visually degraded or partially degraded conditions.

## Current Codebase Organization

- `external/ORB_SLAM3`: ORB-SLAM3 project, including existing local tools and results.
- `external/Debias_IMU/rss_debiasing_restart`: Debias_IMU restart project containing `Debias_IMU/BiasDy` training code and existing experiment outputs.
- `external/OpenVINS`: OpenVINS catkin workspace, with source repo under `src/open_vins`.

- `plato/scripts/orbslam3_export`: PLATO-owned LIASuw ORB-SLAM3 trajectory export and evaluation scripts.
- `plato/scripts/train_bias_dynamics`: PLATO-owned Debias_IMU orchestration, LIASuw/EuRoC training, frame checks, and bias-dynamics variants.
- `plato/scripts/openvins_eval`: PLATO-owned OpenVINS input export, bag generation, dropout evaluation, and bias-consistency tools.
- `plato/configs`: PLATO-owned configs for ORB-SLAM3, Debias_IMU, and OpenVINS integration.
- `plato/docs`: project memory and integration documents.

- On 2026-05-17, a new PLATO-owned interval-level preintegration NLL was implemented without modifying `external/Debias_IMU`. This is not the older per-state/endpoint trajectory NLL: each likelihood term is built from one low-rate supervisory interval `[s_m, s_{m+1}]`; endpoint trajectory states are used only to construct the ideal preintegration target, the learned NODE/IMU rollout provides `DeltaR/Deltav/Deltap_hat`, and the residual is `Log(DeltaR_hat.T @ DeltaR_star)`, `Deltav_star-Deltav_hat`, `Deltap_star-Deltap_hat`. New runner controls are `--acc-loss-type interval_nll`, `--interval-nll-mode {mse_only,nll_cov_only,nll_joint}`, learnable raw `sigma_g2/sigma_a2`, optional log-sigma priors, `--interval-detach-covariance-theta` defaulting true, and `--interval-noise-init-model-path` for staged continuation. New corldata configs are `plato/configs/debias_imu/corldata_sparse_endpoint_no_udot_w256_sg101_initmedian5_interval_nll_covonly_from_e301.yaml`, `plato/configs/debias_imu/corldata_sparse_endpoint_no_udot_w256_sg101_initmedian5_interval_nll_joint_lr1e5_from_covonly.yaml`, `plato/configs/debias_imu/corldata_sparse_endpoint_no_udot_w256_sg101_initmedian5_interval_nll_covonly_continue_from_covonly.yaml`, and `plato/configs/debias_imu/corldata_sparse_endpoint_no_udot_w256_sg101_initmedian5_interval_nll_joint_lr1e5_from_covonly_continue.yaml`. ## Intended Algorithmic Pipeline

1. Run ORB-SLAM3 stereo VO on visually favorable datasets.
2. Export accurate camera/pose trajectory estimates.
3. Use these trajectories as privileged supervisory observations.
4. Train Neural ODE models for IMU bias dynamics:
   - gyroscope bias `b_g`
   - accelerometer bias `b_a`
5. Export learned bias trajectories or learned bias dynamics.
6. Inject or evaluate the learned bias information in OpenVINS.
7. Test on visually degraded or partially degraded datasets.

## Assumptions And Uncertainties

- The moved ORB-SLAM3 and Debias_IMU repositories contain local modifications and experiment artifacts; they are not pristine upstream checkouts.
- Some moved project memory in `external/Debias_IMU/rss_debiasing_restart/Debias_IMU/plato_extensions/docs/project_memory` still mentions old absolute paths under `/home/amao/workspace/debiasingIMU/rss_debiasing_restart`.
- The moved OpenVINS workspace includes existing `build/`, `devel/`, `logs/`, and `.catkin_tools/` folders; generated setup files may contain old workspace paths and may need regeneration before building or running.
- The paper submodule was cloned from the committed state of the local Overleaf repo. At the time of addition, the original local Overleaf checkout had uncommitted `main.tex` changes and untracked LaTeX build artifacts that were not automatically transferred into the submodule clone.
- LIASuw paths include spaces and non-ASCII directory names in some calibration and mocap folders; future scripts should use `pathlib.Path` and avoid unquoted shell paths.
- EuRoC, LIASuw, and corldata should remain outside git under `/home/amao/datasets`; `PLATO/datasets/` should only hold ignored local symlinks or small manifests.
- PLATO currently supports both offline corrected-IMU OpenVINS evaluation and opt-in OpenVINS learned-bias propagation hooks. The offline corrected-IMU route is the cleaner current evaluation path; the direct learned-bias hook still needs state/offset adaptation before self-initialized deployment claims.
- ORB-SLAM3 trajectory frame conventions must be verified for each dataset before using trajectories as bias supervision. `0912s15` is explicitly rejected and should not be used for training.
- Do not assume left camera, IMU/body, and motion-capture body frames are the same across datasets or sequences. Any fixed frame rotation estimated from data must be treated as sequence/session-specific until validated against a real extrinsic calibration or across multiple sequences.
- Future Debias_IMU training should randomly sample local trajectory windows from usable pseudo-groundtruth sequences. Candidate window lengths may include 32 and 64, and maximum window length should not exceed 256. Before using a sampled window, evaluate local pseudo-groundtruth quality and use only windows with sufficiently low RMSE / high trajectory accuracy.
