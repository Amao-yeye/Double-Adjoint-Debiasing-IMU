# PLATO Agent Memory

Project name: **PLATO**

Full title: **PLATO: Privileged Learning from Accurate Trajectory Observations for IMU Bias Dynamics**

## Research Goal

PLATO aims to use high-quality trajectories from ORB-SLAM3 stereo visual odometry/SLAM on visually favorable datasets as privileged supervisory trajectory observations. Because these are teacher trajectories rather than deployment-time estimates, ORB-SLAM3 loop closure is allowed and desirable when it improves trajectory quality. These trajectories will supervise learning of IMU bias dynamics, including gyroscope bias `b_g` and accelerometer bias `b_a`, with bias dynamics modeled by Neural ODEs. Learned or estimated bias information will then be injected into or evaluated inside OpenVINS to test whether IMU propagation and VIO remain accurate for longer during visually degraded segments.

## External Project Roles

- `external/ORB_SLAM3`: high-accuracy stereo visual-only teacher trajectory generation, with loop closure allowed for pseudo-GT creation.
- `external/Debias_IMU/rss_debiasing_restart`: Neural ODE based IMU bias dynamics learning.
- `external/OpenVINS`: downstream VIO evaluation with learned or corrected IMU bias dynamics.
